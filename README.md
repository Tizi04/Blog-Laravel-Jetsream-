# Post Manager - Laravel & Livewire

## Descripción

**Post Manager** es una aplicación web para gestionar y editar publicaciones. Los usuarios autenticados pueden crear, editar y eliminar sus posts de manera sencilla. El proyecto utiliza **Laravel** como backend, **Livewire** para interactividad en tiempo real y **Jetstream** para la autenticación de usuarios.

## Características

- ✅ **Gestión de Posts**: Los usuarios pueden crear, editar y eliminar publicaciones.
- ✅ **Validación de Formularios**: Los datos de los formularios se validan en el servidor antes de ser enviados.
- ✅ **Interactividad en Tiempo Real**: Usando Livewire, los formularios se actualizan sin necesidad de recargar la página.
- ✅ **Control de Accesos**: Solo los usuarios autenticados pueden modificar sus propios posts.
- ✅ **Mensajes de Retroalimentación**: Los usuarios reciben mensajes de éxito o error después de interactuar con los formularios.
- ✅ **Autenticación y Registro**: Usando **Jetstream**, el proyecto gestiona el registro, autenticación y verificación de usuarios.

## Tecnologías Usadas

- **Laravel**: Framework PHP para el backend.
- **Livewire**: Librería para construir interfaces interactivas sin JavaScript.
- **Jetstream**: Framework para gestionar la autenticación de usuarios, incluyendo funciones como el inicio de sesión, el registro y la verificación de correo electrónico.
- **Blade**: Motor de plantillas de Laravel para vistas dinámicas.
- **Tailwind CSS**: Framework de CSS para un diseño responsive y moderno.
- **Authentication**: Sistema de autenticación de Jetstream para gestionar usuarios.
